# Authored path and string-value evidence

`paths.xml` is the newly authored synthetic XML from the BSC-8 source investigation,
with original CRLF and literal attribute tabs retained. `saxon-18.txt` contains
18 independently reproduced rows from Saxon HE 12.9 in pinned KoSIT validator
1.6.3, using the original `schxslt:location` function. These are source-model tests,
not invoice fixtures, rule execution, held-out labels or acceptance evidence.

`cargo +1.83.0 test --offline --locked -p einvoice-source` checks the current Rust
arena against these fixed rows. Expected values are not generated by the source
implementation. Rows retain codepoints, occurrence order and duplicates.

Optional developer replay, from a clean checkout with Python 3.11+:

```sh
python3 crates/einvoice-source/tools/replay_saxon.py \
  --jar /path/to/validator-1.6.3-standalone.jar \
  --java-home /path/to/corretto-27.0.1.0.11/Contents/Home \
  --source-archive /path/to/xrechnung-3.0.2-validator-configuration-2026-08-31.zip
```

No command reads or needs `.scratch`, downloads anything, modifies expected rows,
or executes an invoice rule. The source archive is required: the script extracts
only the original location function into a temporary wrapper, verifies its hash,
and compares exact output against the 18 retained rows. It refuses wrong archive,
JAR, function or runtime payloads and subprocess failures/timeouts.

The Corretto pin is a complete installed-payload fingerprint, **not an upstream
archive checksum or independent attestation of installation provenance**. The
script hashes sorted relative names and SHA-256 file contents, including symlink
names/targets, and checks exact `Corretto-27.0.1.0.11` / `27.0.1+11-FR` release
metadata. On another platform use `--corretto-tree-sha256` with an independently
verified image fingerprint for that same release. Platform archive verification
is the caller's prerequisite; this script never silently accepts an unknown image.
